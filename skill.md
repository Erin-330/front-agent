# Front Agent Skill

## Purpose
Automates frontend development tasks: component scaffolding, code review, style consistency, and shipping.

## Triggers
- User asks to build or modify a UI component
- User asks to review frontend code
- User asks to ship, deploy, or release frontend changes
- User references `.tsx`, `.jsx`, `.css`, `.scss` files

## Capabilities
- Scaffold React/Next.js components with TypeScript
- Review and fix accessibility issues
- Enforce consistent styling patterns
- Run build checks before shipping
- Commit and push via the ship command

## Usage
```
/ship          — build, commit, and push changes
```
